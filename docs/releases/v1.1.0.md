# QRick 1.1.0

Generate and scan QR codes. Everything stays on your device.

- Scan QR codes using your camera, copy the decoded text, explicitly open web links, or generate a QR code from a scan result.
- Process camera images locally and stop the camera automatically after a successful scan.
- Prefer native QR detection with a bundled JavaScript fallback in extensions. The bookmarklet uses native detection only.
- Improve desktop popup sizing and refresh generation and scanning artwork.

## Install Firefox

- [Mozilla Add-ons listing — current version](https://addons.mozilla.org/firefox/addon/qrick/)
- [Firefox 1.1.0 — Mozilla-signed XPI](https://addons.mozilla.org/firefox/downloads/file/5267185/qrick-1.1.0.xpi)

Mozilla approved version 1.1.0 on November 17, 2026. The signed XPI is hosted by Mozilla and is separate from the unsigned ZIP attached below.

## Release assets

- `qrick-firefox-v1.1.0.zip`: unsigned package for Mozilla submission or temporary developer loading; use the signed XPI above for normal installation.
- `qrick-chrome-v1.1.0.zip`: Chrome/Edge submission package; extract it for local developer loading.
- `qrick-safari-v1.1.0.zip`: Safari conversion and packaging input; containing-app signing and device testing remain required.
- `qrick-source-v1.1.0.zip`: source archive and reviewer build instructions, not an installable add-on.
- `SHA256SUMS.txt`: checksums for the attached ZIP archives; these do not cover the externally hosted signed XPI.
